# Ninh Studio

Marketing site for [Ninh Studio](https://ninhstudio.ca), a photography studio on Joyce Street in East Vancouver.

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`RESEND_API_KEY` in `.env.local` is optional; contact form submissions fall back to a mailto link without it.

## Scripts

```bash
npm run dev    # next dev
npm run build  # next build
npm run start  # next start
npm run lint   # eslint
```
